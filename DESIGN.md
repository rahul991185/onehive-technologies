## Brand & Style
The design system channels an executive-grade, deep-tech intelligence aesthetic. It communicates autonomous precision, mission-critical infrastructure reliability, and high-velocity clarity. The visual language blends ultra-crisp architectural minimalism with functional glassmorphism and radiant energy points. 

Surfaces are pristine, bright, and deliberate—eschewing clinical sterility through luminous honey-gold energy channels and precision telemetry cyan accents. It evokes command, absolute clarity of data, and effortless operational superiority.

## Colors
The palette balances pure light refraction with high-density ink contrast and resonant photonic accents.

- **Canvas & Surface Architecture**:
  - `Surface Pristine` (`#FFFFFF`): Primary card, modal, and floating workspace layer.
  - `Surface Porcelain` (`#F8FAFC`): Base application canvas and global backdrop.
  - `Surface Elevated` (`#F1F5F9`): Inactive controls, segmented track wells, and table header bands.
  
- **Obsidian Typography Scale**:
  - `Text Primary` (`#0F172A`): Maximum optical contrast for primary numbers, metrics, and structural titles.
  - `Text Secondary` (`#1E293B`): Body discourse, operational logs, and field titles.
  - `Text Muted` (`#334155`): Metadata, structural labels, and inactive iconography.
  
- **Hive Core (Amber/Gold)**:
  - Primary interactive drivers and high-salience states utilize `#D97706` for rich interactive buttons and focus states, energized by `#F59E0B` for illuminated active markers, indicators, and warning telemetries. Deep anchoring occurs at `#B45309`.
  
- **Telemetry & Signal (Cyan/Azure)**:
  - High-frequency operational readouts, streaming sync badges, and linked systems use `#0284C7` (primary telemetry) and `#0EA5E9` (active signal ping).

- **Boundary Glass Tinting**:
  - Base structural strokes: `rgba(15, 23, 42, 0.06)`
  - Active/Focused boundaries: `rgba(217, 119, 6, 0.28)`
  - Telemetry highlights: `rgba(2, 132, 199, 0.25)`

## Typography
The system uses an engineered triple-font structure to cleanly segment architecture, readability, and machine telemetry:

- **Display & Section Headers (`Space Grotesk`)**: Technical, structured, and geometric. It anchors high-level executive dashboards and module titles with mathematical authority.
- **Continuous Reading & System Interface (`Hanken Grotesk`)**: Neutral, sharp, and highly legible. It carries tabular parameters, dense forms, and complex instructions without visual friction.
- **Metrics, Data Identifiers, & Telemetry (`JetBrains Mono`)**: Strict character widths for live log readouts, system state badges, coordinates, and real-time streaming counts.

All headline levels above 30px collapse gracefully onto mobile breakpoints to ensure dense numerical readouts never induce uncalculated page overflows.

## Layout & Spacing
The layout uses an adaptive 12-column mathematical grid, framed by strict geometric proportions.

- **Desktop (1200px+)**: 12-column fluid grid, 2rem margins, 1.5rem gutters. Shell modules expand symmetrically to a max content containment of 1440px to preserve visual scan density.
- **Tablet (768px - 1199px)**: 8-column layout, 1.5rem margins, 1rem gutters. Control sidebars tuck into collapsibles.
- **Mobile (< 768px)**: 4-column layout, 1rem margins, 1rem gutters. Dense vertical stacking; interactive target heights maintain an absolute baseline of 44px regardless of typography compactness.

Spacers run strictly along an 8-point base lattice, using the 4px token (`space-xs`) strictly for micro-alignments such as chip badges, icon pairings, and input-label relationships.

## Elevation & Depth
Elevation balances crisp optical lines with ethereal, calibrated diffusion. Rather than heavy muddied drop shadows, the system deploys directional luminescence and precise semi-transparent glass borders.

- **Level 0 (Canvas Base)**: Pure flat `#F8FAFC`. Zero elevation.
- **Level 1 (Structural Modules & Data Panels)**: `#FFFFFF` surface backed with an ultra-fine border `1px solid rgba(15, 23, 42, 0.06)` and shadow `0 1px 3px rgba(15, 23, 42, 0.04), 0 1px 2px rgba(15, 23, 42, 0.02)`.
- **Level 2 (Hovered Panels & Elevated Cards)**: `#FFFFFF` surface backed with `1px solid rgba(15, 23, 42, 0.08)` and shadow `0 10px 25px -5px rgba(15, 23, 42, 0.06), 0 8px 10px -6px rgba(15, 23, 42, 0.04)`.
- **Level 3 (Command Overlays, Menus, Drawers)**: Pure white `#FFFFFF` layered with `backdrop-filter: blur(12px)` when overlapping content, bounded by `1px solid rgba(245, 158, 11, 0.20)` and an ambient shadow `0 20px 30px -10px rgba(15, 23, 42, 0.10), 0 0 0 1px rgba(0, 0, 0, 0.03)`.
- **Active Radiant States**: Critical live system telemetry cards project an amber aura through `box-shadow: 0 0 20px -3px rgba(245, 158, 11, 0.15)`.

## Shapes
To reinforce an industrial-grade, precision-engineered feel, shapes favor tight, architectural discipline over playful curves.

- **Base Components**: Inputs, buttons, chips, and table line highlights feature `0.25rem` (4px) corner radii.
- **Structural Containers**: Small widgets, cards, and modal shells deploy `rounded-lg` (`0.5rem` / 8px).
- **Master Canvases & Drawers**: Flyout drawers and global dashboard viewports deploy `rounded-xl` (`0.75rem` / 12px).
- **System Tags & State Dots**: Retain absolute technical identity via pill rounding (`9999px`) purely for micro numeric counters and live telemetry status pins.

## Components

### Buttons
- **Primary Kinetic (Amber)**: Deep honey fill (`#D97706`), text in `#FFFFFF`, crisp `1px solid rgba(180, 83, 9, 0.3)` border. On hover: transitions to `#B45309` with a subtle amber photonic glow (`0 0 12px rgba(245, 158, 11, 0.35)`).
- **Secondary Telemetry (Cyan Stroke)**: Transparent background, `1px solid rgba(2, 132, 199, 0.35)`, text in `#0284C7`. On hover: surface tints to `rgba(2, 132, 199, 0.06)` with border sharpening to `#0284C7`.
- **Subtle / Ghost**: Transparent fill, text in `#334155`. On hover: surface `#F1F5F9`, text `#0F172A`.

### Chips & Telemetry Tags
- Compact height (24px) utilizing `label-badge` typography (`JetBrains Mono`).
- **Telemetry Live**: Background `rgba(2, 132, 199, 0.08)`, border `1px solid rgba(2, 132, 199, 0.3)`, text `#0284C7`. Features an active pulsing 6px radial dot.
- **Amber Warning/Alert**: Background `rgba(245, 158, 11, 0.10)`, border `1px solid rgba(245, 158, 11, 0.35)`, text `#B45309`.

### Input Fields & Controls
- **Text Inputs**: Base background `#FFFFFF`, border `1px solid rgba(15, 23, 42, 0.12)`, text `#0F172A`, placeholder `#94A3B8`.
- **Focus State**: Border shifts instantaneously to `#D97706`, accompanied by an outer micro-ring: `0 0 0 2px rgba(217, 119, 6, 0.15)`.
- **Checkboxes & Radios**: 16px square/circle with `0.25rem` corners. Selected state exhibits deep amber `#D97706` fill with white architectural checkmark icon.

### Cards & Module Frames
- High-contrast pure white panels (`#FFFFFF`) framed by micro-borders `rgba(15, 23, 42, 0.06)`.
- Cards incorporate top-edge accents: a 2px hairline header indicator using `#D97706` for operational modules and `#0284C7` for active real-time data feeds.

### Data Tables & Event Logs
- Table headers set in `#F8FAFC` utilizing `label-code` uppercase styling.
- Row divider lines use `rgba(15, 23, 42, 0.04)`.
- On row-hover, apply an instantaneous light tint (`rgba(245, 158, 11, 0.03)`) with the left 3px boundary shifting to active amber (`#D97706`).
